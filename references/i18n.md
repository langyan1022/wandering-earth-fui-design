Multi-language support, starting with English (`en`) and Simplified Chinese

## 1. Principles

- **Every string comes from a message catalogue.** No user-facing text is
  hard-coded in markup or scripts, including `aria-label`, `title`, and
  placeholder text.
- **English and Chinese are peers.** Both get complete catalogues; neither is
  a fallback that leaks into the other's screen.
- **Telemetry is language-neutral.** Numbers, units, identifiers, codes,
  coordinates, and timestamps look the same in every language.
- **The layout holds in both.** No label has a fixed width; nothing is
  designed around the length of the English word.
- Adding a language later means adding one catalogue and, if its script
  needs it, one type rule block. Nothing else changes.
- The catalogue is written for left-to-right scripts. A right-to-left
  language additionally needs the physical `left` / `right` rules mirrored
  (leading bars, markers, text alignment in tables).

## 2. Language plumbing

If the project already has an i18n library, use it and keep its conventions.
The pattern below is the dependency-free fallback.

```html
<h2 class="fui-panel__title" data-i18n="panel.thrust">Thrust output</h2>
<button class="fui-btn fui-btn--icon" type="button" data-i18n-label="action.close" aria-label="Close panel">
  <svg class="fui-icon" viewBox="0 0 16 16" aria-hidden="true"><path d="M3 3l10 10M13 3L3 13"/></svg>
</button>
```

```js
const messages = {
  en: {
    'panel.thrust': 'Thrust output',
    'action.close': 'Close panel',
    'state.nominal': 'Nominal',
    'state.degraded': 'Degraded',
    'alert.tripped': '{id} tripped at {temp} K',
  },
  'zh-CN': {
    'panel.thrust': '推力输出',
    'action.close': '关闭面板',
    'state.nominal': '正常',
    'state.degraded': '降级',
    'alert.tripped': '{id} 在 {temp} K 时跳闸',
  },
};

let locale = 'en';

/** Keys requested but absent from the active catalogue. Assert it is empty in tests. */
export const missingKeys = new Set();

/** Translate a key; {name} placeholders are filled from params. */
export function t(key, params = {}) {
  if (!(key in messages[locale])) missingKeys.add(`${locale}:${key}`);
  const text = messages[locale][key] ?? messages.en[key] ?? key;
  return text.replace(/\{(\w+)\}/g, (_, name) => params[name] ?? '');
}

/** Switch language: updates <html lang>, all tagged nodes, and the stored preference. */
export function setLocale(next) {
  locale = next in messages ? next : 'en';
  document.documentElement.lang = locale;
  for (const el of document.querySelectorAll('[data-i18n]')) el.textContent = t(el.dataset.i18n);
  for (const el of document.querySelectorAll('[data-i18n-label]')) el.setAttribute('aria-label', t(el.dataset.i18nLabel));
  for (const el of document.querySelectorAll('[data-i18n-placeholder]')) el.placeholder = t(el.dataset.i18nPlaceholder);
  for (const el of document.querySelectorAll('.fui-lang__opt')) el.setAttribute('aria-pressed', String(el.lang === locale));
  try { localStorage.setItem('fui-locale', locale); } catch { /* storage unavailable: keep the session value */ }
}

/** Initial language: stored choice, then the browser's, then English. */
export function initialLocale() {
  let stored = null;
  try { stored = localStorage.getItem('fui-locale'); } catch { /* ignore */ }
  if (stored && stored in messages) return stored;
  return (navigator.language || 'en').toLowerCase().startsWith('zh') ? 'zh-CN' : 'en';
}
```

- `<html lang>` always reflects the active language; the type rules in §4
  hang off it.
- Dynamic text (messages, log lines, alert details) is built with `t()` and
  named placeholders, never by concatenating fragments: word order differs.
- A missing key falls back to English and is recorded in `missingKeys`; a
  finished build has an empty set for every language.
- Start with `setLocale(initialLocale())`, wire each language option's click
  to `setLocale(option.lang)`, and re-run `setLocale` after inserting new nodes.
- Text that scripts generate (state words, heartbeat words, log lines) is
  produced with `t()` too, and regenerated when the language changes.

## 3. Language switch

A two-cell control in the status strip. Each option is written in its own
language and marked with its own `lang`.

```html
<div class="fui-lang" role="group" aria-label="Language">
  <button class="fui-lang__opt" type="button" lang="en" aria-pressed="true">EN</button>
  <button class="fui-lang__opt" type="button" lang="zh-CN" aria-pressed="false">中文</button>
</div>
```

```css
.fui-lang { display: inline-flex; border: 1px solid var(--fui-line-3); }
.fui-lang__opt {
  min-width: 36px;
  min-height: 22px;
  padding: 0 var(--fui-space-2);
  border: 0;
  background: transparent;
  color: var(--fui-text-dim);
  font: 600 var(--fui-text-micro) / 1 var(--fui-font-sans);
  letter-spacing: var(--fui-track-label);
  cursor: pointer;
  transition: background-color var(--fui-dur-fast) var(--fui-ease), color var(--fui-dur-fast) var(--fui-ease);
}
.fui-lang__opt:lang(zh) { font-size: 0.75rem; letter-spacing: 0.1em; }   /* CJK minimum is 12px */
.fui-lang__opt + .fui-lang__opt { border-left: 1px solid var(--fui-line-2); }
.fui-lang__opt:hover { background: var(--fui-surface-2); color: var(--fui-text-hi); }
.fui-lang__opt:active { background: var(--fui-surface-3); }
.fui-lang__opt[aria-pressed="true"] { background: var(--fui-lit-bar); color: var(--fui-act); }
@media (pointer: coarse) { .fui-lang__opt { min-width: 44px; min-height: 44px; } }
```

Switching language is instant: no page reload, no transition on the text, and
the operator's selection, scroll position, and live data are untouched.

## 4. Type rules per language

Components read size and tracking from tokens, so a language adjusts the
tokens once and every component follows.

```css
/* Chinese: CJK face for running text, larger minimum sizes, lighter tracking. */
.fui:lang(zh) {
  --fui-text-micro: 0.75rem;     /* 12px minimum for CJK */
  --fui-text-label: 0.8125rem;   /* 13px */
  --fui-track-label: 0.1em;
  --fui-track-title: 0.06em;
  font-family: var(--fui-font-cjk);
  font-weight: 400;
  line-height: 1.6;
}

/* Latin fragments inside a Chinese page keep the Latin label metrics. */
.fui:lang(zh) :lang(en) {
  --fui-text-micro: 0.6875rem;
  --fui-text-label: 0.75rem;
  --fui-track-label: 0.12em;
  --fui-track-title: 0.08em;
}
```

| | English | Chinese |
|---|---|---|
| Running text | Rajdhani 500, 15px / 1.45 | Source Han Sans SC (思源黑体 / Noto Sans SC) 400, 15px / 1.6 |
| Labels, buttons, badges | Rajdhani 600, UPPERCASE, 0.12em | sans stack (CJK glyphs fall to Source Han Sans) 600 → renders 500–700, 13px, 0.1em; no case |
| Titles | Rajdhani 600, UPPERCASE, 0.08em | 600, 0.06em |
| Emphasis | weight and case | weight only: Chinese has no case and no italics |
| Numbers, IDs, units | JetBrains Mono | JetBrains Mono — identical |
| Minimum size | 11px | 12px |

- `text-transform: uppercase` is harmless on Chinese and still applies to
  Latin identifiers inside a Chinese label.
- Do not letter-space Chinese running text. Labels and titles take
  0.06–0.1em; the primary line of a bilingual label, a display element, may go to 0.2em.
- Do not fake bold: load 500 and 700 of the CJK face.

## 5. Bilingual label

The film's own device: the Chinese term with a small Latin label beneath. Use
it where both audiences share a screen (control rooms, public displays,
showcase pieces), on navigation and section titles, not on every string.

```html
<span class="fui-bi">
  <span class="fui-bi__primary" lang="zh-CN">导航</span>
  <span class="fui-bi__secondary" lang="en">Navigation</span>
</span>
```

```css
.fui-bi { display: inline-grid; gap: 2px; justify-items: start; line-height: 1; }
.fui-bi__primary {
  font: 500 var(--fui-text-sm) / 1.1 var(--fui-font-cjk);
  letter-spacing: 0.2em;
  color: var(--fui-text-hi);
}
.fui-bi__secondary {
  font: 600 0.625rem / 1 var(--fui-font-sans);
  letter-spacing: 0.12em;
  text-transform: uppercase;
  color: var(--fui-text-dim);
}
```

- The primary is the audience's main language; swap the two spans for an
  English-first screen (primary English 14px uppercase, secondary Chinese 12px).
- The secondary line is a caption: it is the one place 10px Latin is allowed,
  because the primary carries the meaning.
- A bilingual label is one accessible name: set `aria-label` on the control
  to the active language's term, or mark the secondary `aria-hidden="true"`.

## 6. What translates

| Translates | Does not translate |
|---|---|
| Labels, titles, button verbs, tab names | Identifiers: `ENG-0417`, `SU-A03`, `CH-03` |
| State words: `NOMINAL` 正常, `DEGRADED` 降级, `TRIPPED` 跳闸 | Units and symbols: `K`, `%`, `kN`, `Hz`, `°` |
| Messages, hints, empty-state sentences | Numbers and their formatting |
| Axis titles, legend labels | Timestamps `14:02:07Z`, dates `2026-11-21`, countdowns `T-00:42` |
| `aria-label`, tooltips, placeholder text | Coordinates and hemisphere letters `N S E W` |
| Severity words: `INFO` 提示, `WARNING` 警告, `CRITICAL` 严重 | Log level tags in log streams (`INFO`, `WARN`, `FAIL`), error codes, key names (`Esc`, `Enter`) |

## 7. Formatting

- **Telemetry numbers are locale-stable.** Format with a fixed locale so both
  languages show the same digits, decimal point, and grouping:
  `value.toLocaleString('en-US', { minimumFractionDigits: 2, maximumFractionDigits: 2 })`.
- **Prose dates and quantities** inside sentences may use the active locale:
  `new Intl.DateTimeFormat(locale, { dateStyle: 'medium' }).format(date)`.
- **Spacing in Chinese:** one regular space between Chinese text and adjacent
  Latin words or numbers (`推力 98.52 %`, `发动机 ENG-0417 已跳闸`); none before
  `%` or `°` when the product writes them tight; full-width punctuation
  (`，` `。` `：`) in sentences, never in labels.
- **Plurals:** English needs singular and plural forms (`1 engine`,
  `12 engines`); Chinese does not. Keep counts out of the label where
  possible: `ENGINES` / `发动机` with the number in a mono span.
- **Units stay SI.** Do not translate `K` to `开` or `%` to `百分之`.

## 8. Layout tolerance

- English runs 30–100% longer than Chinese for the same label; Chinese glyphs
  are wider and taller per character. Design for both:
  - no fixed widths on labels, buttons, tabs, or table headers;
  - buttons in a row get `min-width: 64px` so `启动` does not collapse;
  - table columns size to content, with the metric columns fixed by `ch`;
  - titles may wrap to two lines in panels narrower than 240px, in either language.
- Line height for Chinese running text is 1.6; component heights (28px rows,
  18px badges) do not change, so single-line labels use `line-height: 1`.
- Truncate only free text, with the full string available on focus or hover.
  Never truncate a label, an identifier, or a number.
- Test every view in both languages at 1440, 768, and 375px.

## 10. i18n checklist

- [ ] `<html lang>` matches the active language and changes with the switch.
- [ ] No hard-coded user-facing string in markup, scripts, `aria-label`, or placeholders.
- [ ] Both catalogues are complete; no raw keys or mixed-language leftovers on screen.
- [ ] Identifiers, units, numbers, timestamps, and coordinates are identical in both languages.
- [ ] Chinese text is ≥ 12px, uses the CJK face, and has no letter-spaced running text.
- [ ] No overflow, truncation of labels, or layout shift when switching language at 1440 / 768 / 375px.
- [ ] Dynamic messages are built from templates with placeholders, not concatenation.
- [ ] The language choice persists across reloads and is announced (`lang` on each option).
